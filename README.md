# Shell & Systems Engineering Basics

Shell scripting exercises from the ALX Software Engineering program — the fundamentals of working on the command line and understanding how a Unix system actually behaves underneath.

## What's in here

- **0x00 – Shell basics** — navigating the filesystem, running commands
- **0x01 – Shell permissions** — file permissions, ownership, `chmod`/`chown`
- **0x02 – Shell redirections** — pipes, redirects, filters
- **0x03 – Shell variables & expansions** — environment variables, string manipulation
- **0x04 – Loops, conditions & parsing** — control flow, argument handling
- **0x05 – Processes & signals** — process management, `kill`, signal handling

Each folder is a set of small, focused scripts — one concept per script rather than a single big project.

## Why this is here
These aren't flashy, but they're the fundamentals that everything else — servers, deployment, automation — sits on top of. Good to know cold before building anything more complex on Linux.
